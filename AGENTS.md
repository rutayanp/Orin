# Engineering governance

Repository owner is architecture gatekeeper. All material architectural changes require explicit owner approval through PR or recorded instruction before merge. Do not merge on behalf of owner without explicit authorization. Record decisions in docs/adr. Keep changes small, testable and portable. No paid AI APIs, secrets, personal data, model weights or unnecessary dependencies. Report tests actually run and unresolved risks. Do not bypass domain validation or expose unauthenticated services beyond loopback.
