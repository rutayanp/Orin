# ADR 0001 — Foundation
Status: Proposed; owner approval pending.

Choose modular Python application with native inference runtimes, SQLite relational state plus audit, local model adapters, and REST-first iPhone communication. Alternatives: all-C++, microservices, event sourcing, streaming-first, vector database. Rejected initially because they increase complexity without demonstrated benefit. Revisit with profiling or concrete requirements. OpenClaw protocol and versions require compatibility spike; iOS delivery/signing and production security details require follow-up review.
